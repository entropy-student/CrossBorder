# CrossBorder

CrossBorder is a Medusa 2.19 + Next.js 15 commerce project snapshot.

## Current status

The project is intentionally paused after governance and repository cleanup.

Future payment and fulfillment are intended to integrate with another already-running system rather than continue as a fully self-developed CrossBorder subsystem.

Existing PayPal/reconciliation code is preserved as historical/reference implementation and remains disabled by default. It is not the selected production path.
